📘 Chapter 15: CSS Colors

Color names, HEX values, RGB values, and grey color shades in CSS.

04 Color Topics

5.1 Color Names

CSS supports over 140 named colors.

Red
Blue
Green
Orange
Purple
p { color: red; }

5.2 HEX Colors

Colors can be defined using HEX codes.

#FF0000
#00FF00
#0000FF
#FFA500
p { color: #ff0000; }

5.3 RGB Colors

RGB means red, green, and blue color values.

RGB(255,0,0)
RGB(0,255,0)
RGB(0,0,255)
RGB(255,165,0) 
p { color: rgb(255, 0, 0); }

5.4 Grey Colors

Grey shades can be created using HEX or RGB values.

#111111
#555555
#888888
#CCCCCC 
p { color: #888888; }
